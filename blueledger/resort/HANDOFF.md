## 6. PHP 버전 구조

자세한 내용은 같은 폴더 `README.md`. 요점만:

- 주소 `/blueledger/resort/`. 출장여비 화면 상단 이름 메뉴에서 '리조트 예약'으로 이동
- 로그인: 포털 세션(`lib/bootstrap.php` 의 `current_user()`). 직원 명단 = `portal_users`. 리조트 전용 비밀번호 없음
- DB: 포털 DB. 표 정의는 `blueledger/db.php` 의 `BL_SCHEMA` (출장여비 표와 같은 곳), 첫 접속 때 자동 생성
- 영수증: `blueledger/var/resort/` (출장여비 영수증과 같이 웹 직접 접근 차단)
- 크론 · 파이썬 필요 없음. `tools/cleanup.php`(버려진 첨부 정리)만 선택

| 파일 | 역할 |
|---|---|
| `index.php` | 화면 (포털 상단바 + 6개 탭). 로그인 안 했으면 포털 로그인으로 보냄 |
| `api.php` | 조회 · 저장 · 삭제 · 설정 · 영수증 · 관리자 지정 |
| `lib/bootstrap.php` | 포털 로그인 사용자, DB, 공통 함수 |
| `lib/repo.php` | 저장 규칙(직원 수정 범위 서버 검사), 첨부파일, 설정, 관리자 권한 |
| `lib/view_app.html`, `assets/app.js`, `assets/app.css` | 화면 |
| `tools/import_seed.php` | 기존 16건 · 설정 넣기 + 검산 (여러 번 실행해도 안전) |
| `tests/smoke.php` | 자동 시험 40개 (로컬 SQLite 에서만) |

DB 표: `bl_resort_roles`(관리자), `bl_resort_settings`(담당 · 회원권 · 결제수단 · 안내문), `bl_resort_limits`(연도별 한도), `bl_resort_bookings`(예약), `bl_resort_meals`(식대 줄), `bl_resort_files`(영수증), `bl_resort_log`(작업 기록)

로그인 · 보안
- 아이디 = 회사 이메일(포털 계정). 비밀번호 발급 · 변경도 포털에서
- 직원에게는 본인 예약만 서버가 내려줌. 본인 예약 = 본인이 올린 것 + 직원 이름이 본인 포털 이름과 같은 것
- 직원은 '신청' 상태에서만 예약 내용, '확정' 후 정산 전까지만 식대 · 영수증 수정
- 영수증: 이미지 · PDF만 (파일 내용으로 확인), 본인 · 관리자만 열람
- 동시 수정 충돌 안내, 모든 쓰기에 화면 토큰(CSRF), 작업 기록
- 로그인 시도 횟수 제한은 이제 포털 로그인 몫인데 포털에 아직 없음 (BlueLedger README '알려진 남은 일')
